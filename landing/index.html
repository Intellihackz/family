The token page, with a room for its holders.

family adds a chat to every token page. If you hold the token, you are in the room. If you do not, you see a locked door and how many holders are already inside.

Why a gated room

Skin in the game filters most of the noise.

Questions like whether the dev is still holding get asked in places anyone can shout in. Here, only holders can speak.

Holders only

The gate does most of the moderating. Everyone talking is exposed to the same token you are.

The dev is always marked

Devs get a green tag, even after selling, so you can see when they speak and how much they hold.

Position on every message

Each message shows the sender's share of supply, so a big holder and a tiny one never look the same.

A real holder count

Locked rooms show how many holders are inside, with the bonding curve and burn address left out.

Native on the page

It follows the site's light and dark theme and tucks away into a single button when you want the page back.

Independent and clear about it

Community built and not affiliated with pons. Every panel says so, and it never asks you to sign anything.

Install alpha

Add it to Chrome in a minute.

family is not on the Chrome Web Store yet, so for now you load it by hand. It works in Chrome and other Chromium browsers like Brave and Edge.

  1. Download and unzip

    Unzip it somewhere permanent. Chrome runs the extension straight from that folder, so do not delete it afterwards.

    Download alpha v0.1.0

  2. Open the extensions page

    Paste this into a new tab. Links to it are blocked, so it has to be typed or copied.

    chrome://extensions

  3. Turn on Developer mode

    The switch is in the top right corner of that page.

  4. Load the folder

    Click Load unpacked and choose the folder you unzipped.

  5. Pin it and open a token

    Pin family from the puzzle icon, then open any token page on ponsfamily. The room appears bottom right.

alpha

Good to know

  • Expect rough edges. This is an early build and things will change.
  • Updates are manual. Download the new zip, replace the folder, then press reload on the family card in chrome://extensions.
  • What it sees. It only runs on ponsfamily.com. It sends your wallet address and the token to its server to check your balance, and it never asks you to sign or send anything.
  • Developer mode warning. Chrome may show one now and then for hand-loaded extensions. That is normal.
